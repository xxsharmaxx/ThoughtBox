# ThoughtBox Screenshots

After running the application, capture screenshots of:

1. **Thought Feed** — The main feed page with thoughts displayed
2. **Create Thought** — The "Share a Thought" modal form
3. **Category Filter** — Feed filtered by a specific category
4. **Like & Report** — A thought card showing like/report actions
5. **Moderator Login** — The moderator secret prompt
6. **Moderation Panel** — The panel showing all thoughts with hide/unhide
7. **Mobile View** — The responsive mobile layout (use browser DevTools)
8. **Docker Desktop** — Docker Desktop showing running containers
9. **API Docs** — FastAPI Swagger UI at http://localhost:8000/docs
10. **Health Check** — Browser or terminal showing /api/health response

## How to Capture

### Using Windows Snipping Tool
- Press `Win + Shift + S` to open Snipping Tool
- Select the area and save

### Using Browser DevTools for Mobile
- Press `F12` → Click the device toggle icon (or `Ctrl+Shift+M`)
- Select a mobile device preset
- Take a screenshot

Save all screenshots in this folder as PNG files.
